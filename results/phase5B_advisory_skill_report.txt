Runtime contract
- HTTP service binds only to 127.0.0.1. Endpoints: GET /health, GET /metadata, POST /decide, and token-protected POST /shutdown.
- The Python client rejects non-loopback URLs, checks frozen provenance, validates schema, and fails closed on unavailable service, malformed response, or missing false-autonomy guard.
- A request may contain state and optional task. When task is supplied it is included with the state in the runtime evidence object; it is not silently discarded.
- Raw and calibrated stage distributions are passed through. Entropy, normalized entropy, concentration, top probabilities, and margin are distribution properties and are not correctness probabilities.
- Experimental policy result may be CLEAR or REVIEW_REQUIRED, but autonomy_policy.authorizes_autonomous_execution is always false. The Codex and Claude instructions state that CLEAR is not execution authorization and Laya is advisory, not a truth verifier.
- Invalid JSON, invalid schema, unavailable inference, and provenance failures return explicit errors. No fabricated decision or silent continuation is used.
